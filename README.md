One word for the boss: **Seagull**.

The seagull manager: swoops in out of nowhere, squawks loudly over work he never touched, makes a mess of everything, then flies off leaving the team to clean up. Every office has one — and that is the whole entry, exactly one word, no phrase, no caption, no explanation.

`main.py` writes the word to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```
